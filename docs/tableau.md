# Tableau

The workbook is **generated**, then opened in Tableau Desktop Public Edition. Everything is a Tableau calculated field you can read and edit.

## Commands
```
python -m tracker.tracker --adapter browser --export-tableau   # fetch your real marks (Chrome logged in to the ERP) and write the data files
python scripts/build_tableau_workbook.py                       # once: writes tableau/SistPerf_Live.twbx (real) and tableau/SistPerf_Demo.twbx (synthetic)
```
Needs `pip install tableauhyperapi` (Tableau Public only opens workbooks that use extracts, so the workbook is packaged with them).
If Windows blocks the Hyper DLL (error `0x11c7`), the script still works: it packages **empty** extracts, and in Tableau you choose **Data > (source) > Extract > Refresh** for each of the 5 sources to load your data.
When marks change: run the first command again, then in Tableau choose **Data > (each source) > Refresh Extract**. Do not rerun the second command: it would overwrite edits made in Tableau.

## Dashboards (11)
| Dashboard | Contents |
|---|---|
| Home | 12 KPI tiles, overall trend, CAE 1 vs CAE 2, semester performance, subject heatmap, CAE improvement, consistency, SGPA, grade distribution, forecast, results table |
| Assessment Analysis | CAE comparison, CAE improvement, Internal vs Exam, assessment contribution, progression within each semester |
| Subject Analysis | heatmap, subject ranking, variation, range, attendance vs marks |
| Semester Analysis | trend, semester performance, SGPA, CGPA progression, grades |
| Academic Timeline | every assessment in order (the ERP gives no exam dates) |
| Goals and What-if | sliders: expected exam mark, target grade. Projected total, projected SGPA, exam mark needed for the goal |
| Performance Prediction | forecast with range, back-test (predicted vs actual), error, model info |
| Attendance | percent, risk ranking, what-if, future attendance, bunk planner, classes to recover (needs attendance data) |
| Early Warning | success score, pass-risk list with evidence, exam mark needed to pass |
| Live Data and Sync | sync history, mark-change history, data-quality checks, last successful sync |
| Detailed Marks | every mark with grade, plus the ERP's own result |

Quick filters (Academic year, Semester, Subject, Assessment type) are shared across sheets. Clicking a bar or heatmap cell filters the other charts.

## Rules (SIST Regulations, B.E. CSE Data Science R2023)
Total = 50% Internal + 50% Exam (labs 25 + 25). RA if the exam is under 30% or the total under 50%. Grades: A++ 90+, A+ 80, B++ 70, B+ 60, C 50 (points 10, 9, 8, 7, 6). RA subjects are excluded from SGPA and CGPA. Credits and maximum marks: `data/curriculum_r2023_cse_ds.csv`; override credits in `credits.csv`.
Until the Internal mark is published, **estimates use your CAE average** and say so on the dashboard.

## Data files (data/private/tableau/)
`marks_long.csv` (every mark, plus credits and attendance), `predictions.csv`, `change_history.csv`, `sync_log.csv`, `data_quality.csv`, `credits.csv`.
`predictions.csv` comes from `scripts/predict.py`: linear regression on the CAE average versus a plain baseline, chosen by leave-one-out error, trained only on earlier semesters. These are estimates with a range, never results.

## Not included (needs data the ERP capture does not have yet)
Daily attendance calendar, consecutive-absence detector and attendance timeline (need daily attendance records), class averages or rank (the ERP only gives your own data), and attendance for the Live workbook until `data/private/attendance.csv` exists.
For a PDF report use Tableau's Dashboard > Export as PDF.

## Publishing
Tableau Public makes data downloadable. Publish only the **demo** workbook. Keep the Live workbook on your computer (File > Save As > Save to your computer).

## If Tableau reports an error opening the workbook
Click Copy Error Message and send it. The workbook is generated by `scripts/build_tableau_workbook.py` and `scripts/twb_lib.py`, so a fix is a small change there.
