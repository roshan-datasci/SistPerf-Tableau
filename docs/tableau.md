# Tableau

The workbook is **generated for you**, then you open it in Tableau Desktop Public Edition.

## Commands
```
python -m tracker.tracker --adapter browser --export-tableau   # fetch your real marks and write the data file (Chrome logged in to the ERP)
python scripts/build_tableau_workbook.py                       # once: writes tableau/SistPerf_Live.twbx (real) and tableau/SistPerf_Demo.twbx (synthetic)
```
Requires `pip install tableauhyperapi` (it builds the data extract that Tableau Public insists on).
Open `tableau/SistPerf_Live.twbx`. When marks change: run the first command again, then in Tableau choose **Data > marks_long > Refresh Extract**. Do not rerun the second command: it would overwrite edits you make in Tableau.
Tableau Public only accepts workbooks that use extracts, which is why the workbook is packaged with one (a `.twbx` is a zip holding the workbook and the extract).

## What is inside
**Dashboards:** Home, Assessment Analysis, Subject Analysis, Semester Analysis, Detailed Marks, Data Quality.
**Sheets:** 6 KPI tiles (overall average, CGPA, centums, arrears, subjects, semesters completed), Score Progress, CAE 1 vs CAE 2, Semester Performance, Subject Heatmap, Internal vs Exam by Subject, Grade Distribution, SGPA by Semester, CAE Improvement, Subject Consistency, Results Table, ERP Results, DQ Assumed Max.
**Calculated fields (all inside Tableau, editable):** Pct, Is Centum, Assessment Label, Max Source, Total Marks, Total Max, Subject Total %, Exam %, Has Exam, Grade, Grade Points, Credit Points, Credits Cleared, SGPA, CGPA, Arrear, CAE 1 Pct, CAE 2 Pct, CAE Improvement, Semesters Completed.

## Rules used (SIST Regulations, B.E. CSE Data Science R2023)
Total = Internal + Exam (50 + 50, labs 25 + 25). RA if Exam < 30% or Total < 50%. A++ 90+, A+ 80, B++ 70, B+ 60, C 50 (grade points 10, 9, 8, 7, 6). RA subjects are excluded from SGPA/CGPA.
Credits and maximum marks come from `data/curriculum_r2023_cse_ds.csv`. Edit `credits.csv` next to the data file to override any credit.

## Data columns (marks_long.csv)
One row per subject and assessment: Student_ID, Academic_Year, Term, Semester, Semester_Label, Subject_Code, Subject, Assessment (CAE 1, CAE 2, Internal, Exam), Assessment_Order, Marks, Maximum_Marks, Max_Is_Assumed, ERP_Total, Result, Credits, Fetched_On.

## Publishing
Tableau Public makes data downloadable. Publish **only the demo** workbook (synthetic data). Keep the Live workbook on your computer: use File > Save As > "Save to your computer".
